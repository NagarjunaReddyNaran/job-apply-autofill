Controlled Input Simulation

This page mimics a React-controlled input: it keeps its own "state" and re-renders the field's value from that state on every keystroke. If the extension just sets el.value = "..." directly (without using the native property setter + dispatching a real "input" event), the value will visibly "snap back" to empty. This is the scenario Feature 4 / "trigger appropriate DOM events" is meant to solve.
